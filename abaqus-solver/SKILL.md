# ABAQUS 求解器技能

本技能可以帮助您启动本地ABAQUS软件求解器进行计算，并实时跟踪和报告仿真计算的完成状态。

## 功能特点

- **支持多种输入格式**：
  - 单个.inp文件
  - 包含多个.inp文件的文件夹
  - 仿真脚本文件（.py、.bat、.sh）
- **采用批处理脚本方式**：在Windows系统上使用批处理脚本执行ABAQUS命令
- **自动检测ABAQUS安装**：支持自动检测常见的ABAQUS安装路径
- **实时状态跟踪**：监控计算进度和状态
- **完成状态报告**：计算完成后自动通知结果
- **跨平台兼容**：支持Windows和Linux系统

## 工作流程

1. **输入处理**：
   - 检测输入路径类型（文件/文件夹）
   - 识别文件类型（.inp、脚本文件）
   - 对于文件夹，扫描所有.inp文件

2. **ABAQUS检测**：
   - 自动检测ABAQUS安装路径
   - 优先检查C:\SIMULIA\Commands\abaqus.bat
   - 检查其他常见安装路径

3. **批处理脚本创建**：
   - 为每个.inp文件创建专用的批处理脚本
   - 构建正确的ABAQUS命令
   - 写入批处理脚本文件

4. **求解器启动**：
   - 执行批处理脚本
   - 启动ABAQUS求解器
   - 监控执行状态

5. **状态跟踪**：
   - 显示实时输出
   - 检测错误和警告
   - 计算执行时间

6. **结果报告**：
   - 报告计算完成状态
   - 显示结果保存位置
   - 汇总批量处理结果

## 使用方法

### 单个.inp文件

**输入**：提供单个.inp文件的完整路径
**处理**：创建批处理脚本并启动ABAQUS求解器处理该文件
**输出**：实时状态和完成报告

### 文件夹批量处理

**输入**：提供包含多个.inp文件的文件夹路径
**处理**：扫描文件夹，找到所有.inp文件并逐个创建批处理脚本执行
**输出**：每个文件的处理状态和最终汇总

### 仿真脚本文件

**输入**：提供仿真脚本文件路径（.py、.bat、.sh）
**处理**：直接执行脚本文件
**输出**：脚本执行状态和结果

## 技术细节

### 核心功能

- **文件类型检测**：自动识别输入文件类型
- **ABAQUS安装检测**：自动检测常见的ABAQUS安装路径
- **批处理脚本创建**：为每个计算任务创建专用的批处理脚本
- **进程管理**：启动和监控ABAQUS求解器进程
- **输出解析**：实时解析和显示ABAQUS输出
- **错误处理**：检测和报告计算错误

### 支持的文件类型

- `.inp` (ABAQUS输入文件)
- `.py` (Python脚本)
- `.bat` (Windows批处理脚本)
- `.sh` (Linux shell脚本)

### ABAQUS调用方式

在Windows系统上，使用批处理脚本执行ABAQUS命令：
```batch
@echo off
echo 正在执行ABAQUS计算...
"C:\SIMULIA\Commands\abaqus.bat" job=作业名 input=输入文件
echo 计算完成!
pause
```

## 系统要求

- **ABAQUS软件**：已安装并配置
- **操作系统**：Windows 7+ 或 Linux
- **Python**：3.6+
- **权限**：足够的文件系统权限和计算资源

## 故障排除

- **ABAQUS未找到**：请确保已安装ABAQUS并存在C:\SIMULIA\Commands\abaqus.bat
- **文件访问错误**：请检查文件路径是否正确，以及是否有足够的文件权限
- **计算失败**：请检查.inp文件语法是否正确，以及模型是否有物理意义
- **内存不足**：对于大型模型，可能需要增加系统内存或优化模型
