## 模型组织关键字

### *Heading
- **用途**: 定义模型标题
- **格式**: `*Heading`
- **说明**: 后续内容为模型的标题描述，通常包含分析类型说明

### *Part
- **用途**: 定义模型部件
- **格式**: `*Part, name=<部件名>`
- **说明**: 模型可以被拆分为多个部件，便于装配管理

### *Assembly
- **用途**: 定义装配体
- **格式**: `*Assembly, name=<装配名>`
- **说明**: 将多个部件组装到一起，定义部件间的位置关系

### *Node
- **用途**: 定义节点坐标
- **格式**: `*Node`
- **说明**: 后续行为节点编号和坐标数据（X, Y, Z）

## 材料关键字

### *Material
- **用途**: 定义材料
- **格式**: `*Material, name=<材料名>`
- **说明**: 每种材料有唯一的名称，后跟材料属性定义

### *Elastic
- **用途**: 定义弹性属性
- **格式**: `*Elastic, type=<类型>`
- **说明**: 定义弹性模量、泊松比等弹性参数
  - ISOTROPIC: 各向同性
  - ORTHOTROPIC: 正交各向异性

### *Plastic
- **用途**: 定义塑性属性
- **格式**: `*Plastic, hardening=<类型>`
- **说明**: 定义屈服应力、塑性应变等塑性参数

### *Hyperelastic
- **用途**: 定义超弹性属性
- **格式**: `*Hyperelastic, material=<类型>`
- **说明**: 用于橡胶类材料，常见类型包括 NEO HOOKE, MOONEY-RIVLIN 等

## 单元关键字

### *Element
- **用途**: 定义单元连接
- **格式**: `*Element, type=<单元类型>, elset=<单元集>`
- **说明**: 定义单元由哪些节点组成

### *Element Type
- **用途**: 定义单元类型
- **格式**: `*Element Type, type=<单元类型>`
- **说明**: 指定单元的类型代码，常见类型包括：
  - C3D8: 8节点六面体单元
  - C3D4: 4节点四面体单元
  - S4R: 4节点壳单元
  - T2D2: 2节点桁架单元

## 边界条件关键字

### *Boundary
- **用途**: 定义边界条件
- **格式**: `*Boundary`
- **说明**: 限制节点的自由度，常见类型包括：
  - ENCASTRE: 完全固定（所有自由度为0）
  - XSYMM: X轴对称
  - YSYMM: Y轴对称
  - ZSYMM: Z轴对称
  - PINNED: 铰接约束

## 载荷关键字

### *Cload
- **用途**: 定义集中载荷
- **格式**: `*Cload`
- **说明**: 在节点上施加集中力或力矩

### *Dload
- **用途**: 定义分布载荷
- **格式**: `*Dload`
- **说明**: 在单元上施加分布载荷（如重力、离心力）

### *Dsload
- **用途**: 定义表面载荷
- **格式**: `*Dsload`
- **说明**: 在表面施加分布压力

### *Pressure
- **用途**: 定义压力载荷
- **格式**: `*Pressure`
- **说明**: 在表面施加压力（正为压入，负为吸出）

### *Temperature
- **用途**: 定义温度载荷
- **格式**: `*Temperature`
- **说明**: 施加温度场或温度变化

## 接触关键字

### *Contact Pair
- **用途**: 定义接触对
- **格式**: `*Contact Pair, interaction=<交互属性>`
- **说明**: 定义两个表面之间的接触关系

### *Surface Interaction
- **用途**: 定义接触交互属性
- **格式**: `*Surface Interaction, name=<属性名>`
- **说明**: 定义接触的摩擦、刚度等属性

## 分析步关键字

### *Step
- **用途**: 定义分析步
- **格式**: `*Step, name=<步名>, nlgeom=<几何非线性>`
- **说明**: 定义分析过程的时间段和求解器设置

### *Static
- **用途**: 静态分析
- **格式**: `*Static`
- **说明**: 进行静态结构分析，忽略惯性效应

### *Dynamic
- **用途**: 动力学分析
- **格式**: `*Dynamic`
- **说明**: 考虑惯性效应的动力学分析

### *Frequency
- **用途**: 频率分析
- **格式**: `*Frequency`
- **说明**: 计算结构的固有频率和模态

### *Heat Transfer
- **用途**: 热传导分析
- **格式**: `*Heat Transfer`
- **说明**: 进行热传导、热对流或热辐射分析

## 示例

### 简单弹性材料定义
```
*Material, name=Steel
*Elastic, type=ISOTROPIC
200000., 0.3
```

### 固定边界条件
```
*Boundary
Part-1-1.Set-1, ENCASTRE
```

### 集中载荷
```
*Cload
Part-1-1.Node-100, 1, 1000.
Part-1-1.Node-100, 2, 500.
```

### 接触对定义
```
*Contact Pair, interaction=Friction
Surface-1, Surface-2
```
